# SONARA · Online Radio

Android-приложение для прослушивания интернет-радиостанций на выбранном языке.

## Стек

- Kotlin
- Jetpack Compose и Material 3
- Clean Architecture
- Media3 ExoPlayer + MediaSessionService для фонового воспроизведения
- Room для избранного и истории
- Coil для изображений станций
- Radio Browser API — публичный каталог без API-ключа

## Возможности

- Шесть языков вещания: русский, английский, китайский, турецкий, итальянский и белорусский.
- Выбор языка при первом запуске и его смена в настройках. На главной странице переключателя языка нет.
- Каталог станций с постраничной загрузкой по 10.
- Подборки по музыкальным жанрам; выдача ограничивается выбранным языком.
- Поиск станций на выбранном языке, с подгрузкой результатов по 10.
- Избранные станции и история прослушивания.
- Фоновое воспроизведение, медиакарточка в шторке Android и управление с экрана блокировки.
- Настройка буферизации, таймер сна и пятиполосный эквалайзер.
- Радиобудильник: время, выбор станции, ежедневное повторение, отключение и восстановление расписания после перезагрузки.
- Переключение между станциями свайпом и кнопками «Предыдущая / Следующая».
- Восемь тем оформления: Неон, Океан, AMOLED, Светлая, Закат, Лес, Розовый кварц и Графит.
- Плеер с увеличенной анимированной визуализацией, названием композиции и исполнителем из ICY/Media3-метаданных.
- Автоматическое переподключение при обрыве эфира — до трёх попыток.
- Иконка SONARA · ONLINE RADIO в фирменной фиолетово-голубой гамме.

## Радиобудильник

1. Открой **Настройки → Радиобудильник**.
2. Выбери время пробуждения.
3. Выбери станцию из избранного или загруженного каталога.
4. Нажми **Установить**.
5. На Android 12+ разреши SONARA устанавливать точные будильники в системных настройках. После возврата в приложение нажми **Установить** ещё раз.

Будильник срабатывает ежедневно по локальному времени устройства. В заданное время приложение запускает выбранный поток через Media3. Расписание восстанавливается после перезагрузки устройства и изменения системного времени. Отключение будильника отменяет следующие срабатывания; уже начавшееся воспроизведение можно поставить на паузу через медиаплеер или уведомление.


## Каталог радиостанций

Источник — публичный Radio Browser API. При первом запуске пользователь выбирает язык вещания. Изменить его можно в настройках. Запросы каталога и поиска ограничиваются выбранным языком. Ответ дополнительно проверяется по языковым метаданным станции. Если вещатель не указал язык, такая станция намеренно не отображается.

- Радиобудильник работает непрерывно до нажатия «Выключить будильник» в уведомлении.
- Уведомление будильника оформлено как активная медиакарточка SONARA с кнопкой остановки.
- Сервис будильника запускается только при срабатывании; когда радио не играет и приложение уходит в фон, Activity отсоединяет MediaController и освобождает неиспользуемый плеер. Остаётся только системное расписание AlarmManager.
- ExoPlayer использует CPU-only wake lock только во время активного воспроизведения, чтобы эфир не прерывался при выключенном экране; после остановки блокировка освобождается.
- При сетевых ошибках радиобудильник повторяет подключение с увеличивающимися интервалами.
- Добавлены режимы «Каждый день» и «Один раз». Одноразовый будильник отключает только будущие срабатывания после запуска, не останавливая уже начавшееся радио.
- При восстановлении foreground service после завершения процесса Android приложение повторно подключает текущий эфир.
- Настройки ежедневного будильника восстанавливаются после перезагрузки устройства и изменения системного времени.
- На Android 12+ требуется разрешить SONARA устанавливать точные будильники через системные настройки.
